# Swift Ship Tracker

## 📌 About

**Swift Ship Tracker** is a Salesforce-based application used to manage and track shipment details efficiently.

## ✨ Features

* Shipment tracking and management
* Shipment status monitoring
* Automated processes using **Salesforce Flow**
* **Agentforce** integration
* User-friendly Salesforce interface

## 🛠️ Technologies

* Salesforce
* Salesforce Flow
* Agentforce
* Lightning
